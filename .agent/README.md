# Cách dùng bộ .agent cho Antigravity
Copy thư mục `.agent` vào GỐC project (cùng cấp package.json).
- rules/      → luôn được áp dụng
- skills/     → tự được gọi khi đúng ngữ cảnh
- workflows/  → gõ /new-module, /db-migration, /ui-polish trong chat
Stitch: thêm MCP server của Google Stitch trong Antigravity (Agent panel → MCP servers) theo hướng dẫn chính thức.
