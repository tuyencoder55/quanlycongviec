# UI — Quy tắc

- Dark mode mặc định (class `dark` trên <html>), có nút đổi sáng/tối.
- Phong cách: tối giản, hiện đại, bo góc lớn (rounded-xl/2xl), khoảng trắng thoáng.
- Dùng shadcn/ui + lucide-react. Không tự viết lại button/dialog/input nếu shadcn có sẵn.
- Màu/spacing/radius lấy từ design tokens (CSS variables trong index.css), không hardcode hex rải rác.
- Responsive: dùng được trên điện thoại (sidebar thu gọn thành menu).
- Khi user yêu cầu "làm đẹp / thiết kế lại màn hình": chạy workflow `/ui-polish` (dùng Google Stitch).
- Với màn hình mới quan trọng: ưu tiên thiết kế bằng Stitch trước, rồi mới code.
